aulaCiencias

Descripcion general del proyecto

aulaCiencias es una plataforma web educativa para gestionar clases particulares de ciencias: permite publicar materiales y temarios, recibir solicitudes de reserva, administrar alumnos, horarios, pagos manuales y contenidos del sitio desde un panel privado.

Resumen

aulaCiencias es una aplicacion web full-stack pensada para una profesora particular de ciencias, enfocada en centralizar la gestion de clases, reservas, alumnos y contenidos educativos. La plataforma permite que estudiantes o familias consulten materiales, temarios y recursos publicos, seleccionen temas de estudio, elijan modalidad de clase, fecha, horario y soliciten una reserva que luego se confirma manualmente por WhatsApp o transferencia.

Experiencia publica

El sitio publico esta construido con React, Vite y TypeScript. Incluye secciones de materiales descargables, temarios, materias, glosario educativo, colegios e instituciones, mapa y el flujo de reserva "Te lo explica Silvi".

  • Consulta de materiales y recursos educativos visibles para estudiantes y familias.
  • Exploracion de temarios por materia, nivel, anio o trayecto educativo.
  • Solicitud de clases con seleccion de objetivos, modalidad, tipo de clase, fechas y horarios.
  • Resumen automatico de duracion estimada, monto y datos para continuar por WhatsApp.

Panel administrativo

El proyecto incluye un panel privado para gestionar el contenido y la operacion diaria. Desde ese panel se pueden administrar reservas, alumnos, tutores, materias, temarios, horarios disponibles, textos del sitio, configuracion visual, precios, cupos y seguridad.

Funcionamiento de reservas

El sistema calcula la duracion y el monto de cada solicitud segun la cantidad de temas, el precio por hora y la configuracion de temas por hora. Tambien valida que el horario no sea pasado, controla el cupo maximo por franja horaria y bloquea temporalmente los horarios con reserva pendiente para evitar superposiciones.

Tecnologia

  • Frontend: React, Vite y TypeScript.
  • Backend: Node.js, Express y TypeScript.
  • Base de datos: PostgreSQL con Drizzle ORM y migraciones SQL versionadas.
  • Autenticacion: bcrypt, JWT en cookies httpOnly, validacion con Zod y roles administrativos.
  • Despliegue local: Docker Compose con PostgreSQL y aplicacion servida en el puerto 8080.
